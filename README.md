# Edge-Native Multilingual Farm Tourism Assistant

An offline-first, zero-server conversational assistant built for local farmers (e.g., Noor) who host international tourists. The system enables seamless multilingual communication between visiting tourists speaking foreign languages and the farmer speaking her local tongue (e.g., Hindi), executing intent classification and neural machine translation entirely on-device on the user's Android phone without incurring server hosting costs.

## 1. Problem Statement & Motivation

Local agritourism offers rural farmers a valuable source of direct revenue. However, linguistic barriers between non-English/multilingual tourists (Spanish, French, German, Italian, etc.) and local farmers who speak regional languages (such as Hindi) prevent clear communication regarding pricing, tour schedules, farm experiences, and produce sales.

Hosting cloud-based LLM APIs or cloud translation services is financially unviable for small-scale rural hosts who cannot afford server infrastructure or recurring token bills. 

**This App** solves this by:
1. Offloading all model inference (BERT intent classification & Google ML Kit on-device translation) directly onto the visitor's Android device.
2. Utilizing a structured 3-tier fallback architecture that combines instant local database lookups, template-guided farmer prompts, and direct neural translation.
3. Keeping running costs to **$0** at runtime while ensuring low latency and privacy.

## 2. Architecture & Pipeline Overview

The system operates across three distinct execution tiers depending on intent classification confidence and database availability.

```
                           [ Tourist Message ]
                                    │
                                    ▼
                 [ Google ML Kit Language Identification ]

                                    │

                     [ Multilingual BERT Classifier ]

                                    │
                  ┌─────────────────┴─────────────────┐
     Confidence >= Threshold             Confidence < Threshold
                  │                                   │
                  ▼                                   ▼
        [ Check Local Database ]            [ Tier 3: Direct Translation ]
                  │                         - Translate query to Noor's lang
         ┌────────┴────────┐                - Noor replies freely in her lang
      Hit                Miss               - Translate reply back to tourist
         │                 │
         ▼                 ▼
   [ Tier 1: Fast ]  [ Tier 2: Template Prompt ]
   - Slot fill DB    - Ask Noor slotted template in her lang
     into template   - Noor enters missing value (e.g. "500")
   - ML Kit translates - Slot fill template & update DB
     to tourist lang   - ML Kit translates to tourist lang
         │                 │
         └────────┬────────┘
                  ▼
         [ Deliver to Tourist ]
```

### Tier 1: Automated Fast-Path (High Confidence + DB Hit)
- **Condition**: Intent is classified with confidence $\ge \tau$, and the target data field is populated in Noor's local configuration database.
- **Workflow**:
  1. Tourist sends natural language query in their native tongue (e.g., Spanish: *"Hola, ¿cuánto cuesta una visita guiada?"*).
  2. Local `mmBERT` classifies intent as `price_tour`.
  3. App queries local database for key `price_tour` $\rightarrow$ returns `500`.
  4. App injects value into base response template: `"The price for a tour is {500} rs"`.
  5. `Google ML Kit On-Device Translate` translates the populated sentence into the tourist's language: *"El precio del tour es de 500 rupias."*
  6. Response delivered instantly to tourist. Zero effort needed from Noor.

### Tier 2: Template-Guided Human-in-the-Loop (High Confidence + DB Miss)
- **Condition**: Intent is classified with confidence $\ge \tau$, but the field is missing from the database.
- **Workflow**:
  1. Intent identified as `price_tour`, but DB lookup returns `null`.
  2. App presents a pre-configured, localized fill-in-the-blank question to Noor in her configured language (e.g., Hindi: *"इस टूर की कीमत क्या है?"*).
  3. Noor simply inputs the missing atomic value (e.g., `"500"`).
  4. App caches this value into the local database for future automated queries.
  5. Template populated: `"The price for a tour is {500} rs"`.
  6. `Google ML Kit On-Device Translate` translates to tourist's language and sends back.

### Tier 3: Direct Two-Way Translation Fallback (Low Confidence / Unstructured)
- **Condition**: Intent classification confidence $< \tau$ or unknown conversational query.
- **Workflow**:
  1. `Google ML Kit On-Device Translate` directly translates the raw tourist message into Noor's language (Hindi).
  2. Noor reads the translated message and responds in free-form text or voice in her native language.
  3. `Google ML Kit On-Device Translate` translates Noor's free-form response back into the tourist's native language.

## 4. Synthetic Data & Template Generation Pipeline

Because fine-tuning mmBERT requires diverse multilingual training sets and farm-specific templates, we utilize high-throughput, low-cost API inference (**Featherless AI** with `deepseek-ai/DeepSeek-V4-Flash-0731` at **$0.28 / 1M tokens**).

### 4.1 Tasks for the Synthetic Pipeline

1. **Synthetic Classifier Dataset**:
   - Generate natural language queries across core Western European tourist languages (Latin script) supported natively by mmBERT and Google ML Kit Translate:
     - English (`eng_Latn`)
     - Spanish (`spa_Latn`)
     - French (`fra_Latn`)
     - German (`deu_Latn`)
     - Italian (`ita_Latn`)
     - *(Host Farmer Language)*: Hindi (`hin_Deva`)
   - *Rationale*: Sticking to standard Latin-script Western languages eliminates tokenization/subword segmentation anomalies, right-to-left formatting quirks, and missing font glyphe issues on budget Android devices.
   - Balanced across farm tourism intents:
     - `price_tour` (Tour pricing and group rates)
     - `price_produce` (Cost of fruits, vegetables, honey, milk)
     - `visitation_hours` (Opening times, seasonal availability)
     - `farm_location_directions` (How to reach, transport, parking)
     - `activities_available` (Fruit picking, cow milking, workshops)
     - `amenities_food` (Restrooms, lunch/tea provision, drinking water)
     - `pet_policy` (Rules for pets/dogs)
     - `booking_reservation` (Advance booking requirements)

2. **Template Pair Generation**:
   - **For Noor**: Slotted fill-in-the-blank prompt in Noor's native language (e.g., Hindi).
   - **For Tourists**: Base English response sentence with `{slot}` placeholders for target values.
